DailyMed 3357af32-f91b-4663-8f86-a2bcee7855ea | ExcenelRTU EZ | DESCRIPTION

EXCENEL RTU EZ Sterile Suspension is a ready to use formulation that contains the hydrochloride salt of ceftiofur, which is a broad spectrum cephalosporin antibiotic. Each mL of this ready-to-use sterile suspension contains ceftiofur hydrochloride equivalent to 50 mg ceftiofur, 2.50 mg polyoxyethylene sorbitan monooleate (polysorbate 80), 6.5 mg water for injection in a caprylic/capric triglyceride suspension.
